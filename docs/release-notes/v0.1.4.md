## Improvements

- **Hooks for every CLI role.** Claude Code, DSH, Gemini, Antigravity, opencode, Codex, Kimi, Cursor, Qoder, iFlow and pi roles now install hooks on their own. In real sessions they have already stopped dangerous wait commands. Copilot is still in progress.
- **Session handoff on by default when the cache is cold.** When a role's cache has expired, the next turn carries the session handoff automatically. No need to reread the full history.
- **Fewer false blocks in the entry table.** The hook no longer flags a fix that is only being planned, or one another role merely mentioned.

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` / `bothouse-linux-arm64` (`chmod +x`, then run)
- **Checksums:** `SHA256SUMS`

macOS: drag **Bothouse.app** into Applications, then double-click. The app is unsigned: **right-click → Open the first time**.

## 改进

- **各家 CLI 角色装上 hook。** Claude Code、DSH、Gemini、Antigravity、opencode、Codex、Kimi、Cursor、Qoder、iFlow、pi 的角色现在会自己装 hook，已经在真实会话里拦下危险等待命令。Copilot 还在做。

- **入口表 hook 少误拦。** 将来时态的计划、别人提到过的修复，不再被当成危险命令拦下。
