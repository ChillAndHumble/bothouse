- Commands (bash-guard): no `pkill -f` (it kills the shell running it); use `kill $(pgrep -f '[x]yz')` or a pid file. Background commands need a timeout (`timeout <s> <cmd>`; on macOS `perl -e 'alarm shift; exec @ARGV' <s> <cmd>`) and no `| tail`/`| head`; end a long-running service with `# long-running-ok`. With HOOK_PROXY set, downloads go through the proxy; add `# direct-ok` when a direct download is really needed.
- Reject foreground gh watch, sleep >=60 seconds and sleep polling loops. DSH also rejects any foreground sleep, repeated polls/read-only commands and a fourth sequential single read-only step. Batched reads, child sessions and outing turns have scoped exemptions. DSH network installs/fetches require a timed background task. Missing session history never fabricates counts.
